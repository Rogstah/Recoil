# 🚀 RECOIL v1.0

**Recoil** is a powerful, all-in-one CLI Swiss Army Knife for network analysis, OSINT, cryptography, and system administration. Packed with over 100 features, it's designed for security researchers, sysadmins, and enthusiasts who need a fast and versatile toolkit in their terminal.

## 🛠 Features

The toolkit is divided into specialized modules for efficiency:

### 🌐 Network & Infrastructure
* **Scanning:** Multi-threaded Port Scanner, Local IP discovery, Subnet calculator.
* **Lookup:** Advanced DNS Lookup, GeoIP Location, WHOIS, and SSL Certificate info.
* **Utilities:** Ping, HTTP Header inspection, and MAC address lookup.

### 🕵️ OSINT (Open Source Intelligence)
* **Social:** Search usernames across multiple platforms.
* **Email:** Validation and format checking.
* **Search:** Google Dork generator and Shodan search integrations.

### 🔐 Crypto & Encoding
* **Hashing:** MD5, SHA-1, SHA-256, SHA-512 generator and verifier.
* **Encoding:** Base64, Hex, Binary, ROT13, and Caesar cipher.
* **Security:** Secure Password & UUID generation.

### 💻 System & Files
* **Monitoring:** Real-time CPU, RAM, and Disk usage.
* **File Ops:** Hex-dumping, string extraction, file splitting/merging, and metadata viewing.
* **Text:** Regex testing, duplicate removal, and frequency analysis.

### 🌍 Web Tools
* **Requests:** GET/POST request simulator.
* **Analysis:** Sitemap & Robots.txt viewer, Redirect chain tracker, and link extraction.
